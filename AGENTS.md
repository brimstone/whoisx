# AGENTS.md

## What this repo is

`whoisx` is a single Go module that ships both a CLI (`cmd/whoisx`) and an importable library (root package `whoisx`). No workspace, no sub-modules, no monorepo. Reads IPs from args or stdin, prints JSON to stdout.

## Core commands

| Task | Command |
|------|---------|
| Build CLI | `make` or `go build ./cmd/whoisx` |
| Lint | `go tool golangci-lint run` (golangci-lint v2 is a Go `tool` dep in `go.mod`, not `PATH`) |
| Lint + fix | `make lint-fix` |
| Pre-commit lint (skips `godox`) | `make pre-commit` |
| Test | `go test ./...` |
| Snapshot release | `goreleaser release --snapshot --clean` |
| Regenerate RIR tables | `go generate ./...` |

Lint must be clean before committing. `make pre-commit` is the commit-time gate.

## Gotchas

- **`go tool` can stall on first run** — the first invocation downloads/extracts golangci-lint into the module toolchain cache. Subsequent calls are fast. If a lint command appears hung, wait, don't kill.
- **`go generate ./...` hits the network** and fetches IANA XML. No network = no generation. It overwrites `ipv4_address_space.go` / `ipv6_address_space.go`, which are **compiled into the package** (only `gen.go` is `//go:build ignore`) and marked `DO NOT EDIT`.
- **`go test ./...` currently passes with "no test files"** — this project has zero test files. CI (`test.yml`) still runs `go test ./...`, so any new test you add becomes the suite's contents. RIR lookups are live-network; tests that exercise `IPLookup` need internet.
- **`release.pem`** is the ECDSA signing private key. It is listed in `.gitignore`, generated by GoReleaser signing (`.goreleaser.yaml`) and by CI (`.github/scripts/write-key`) from `secrets.release_key`, and must never be committed to the repo. The matching public key is hardcoded in `cmd/whoisx/update.go:PublicKey()` — swap them in lockstep.
- **Version is not detected at build time** — `version.go` defaults to `"dev"` and GoReleaser stamps `version.Version/Commit/Date` via `ldflags`. The `update` subcommand depends on a real semver, so local-built binaries report "Current binary is the latest" against `"dev"`.
- **`whoisx` (root) is a built binary** (gitignored) produced by `make`. It's a local build artifact, not source. `make clean` only removes `dist/`.
- **Default command behavior** — `cmd/whoisx/main.go` rewrites `args` to include `whoisx` when no known subcommand is given, so bare `whoisx` == `whoisx whoisx`. This only skips if the arg is `completion` / `__complete` or `--help`.
- **Reading from stdin** requires zero positional args to `whoisx`. Passing any IP argument disables stdin.

## Architecture map

```
root package (whoisx)
├── whois.go                    entry: IPLookup + recursion + WhoisInfo types
├── helper.go                   TCP:43 whois fetch + RPSL line parser
├── arin.go / ripe.go / apnic.go / afrinic.go / lacnic.go
│                               one file per RIR, exposes Check4/Check6
├── ipv6.go                     ipv6prefixes list + addIPv6Prefix()
├── ipv4_address_space.go       generated — first-octet → whois server map (ipv4prefixes)
├── ipv6_address_space.go       generated — initIPv6() populating ipv6prefixes
├── gen.go                      //go:build ignore; regenerates the two tables above
├── version.go                  Version/Commit/Date/Binary, stamped by GoReleaser
└── header.tmpl                 goheader template (see .golangci.yaml)

cmd/whoisx (package main)
├── main.go                     cobra root, default-subcommand rewrite, log/slog
├── whoisx.go                   "whoisx" subcommand (args or stdin → JSON)
└── update.go                   "update" subcommand (selfupdate + ECDSA verify)
```

Recursion is the core behavior (see `iplookuprecurse` in `whois.go`): if a RIR says the address isn't theirs (RIPE → ARIN, APNIC → ARIN, AFRINIC → ARIN; ARIN → APNIC/RIPE/AFRINIC by org name), it re-dials the correct server. Adding a RIR means adding a file + an entry in `lookupFunctions`.

## Conventions

- **License header on every source file** — enforced by `goheader` (`.golangci.yaml` → `header.tmpl`). `// Copyright (c) YYYY Matt Robinson brimstone@the.narro.ws`.
- **Very heavy lint set** — `linters: default: all` with only 22 linters disabled (see `.golangci.yaml`). Tight rules that trip up casual edits: `nlreturn` (blank line before `return`/`continue`), `noinlineerr` (no `if err := ...; err != nil`), `thelper`, `godot`. Run `make lint` to find violations, `make lint-fix` to fix what can be auto-fixed.
- **Go 1.25** is the module floor; the `tool` directive in `go.mod` requires `>=1.24`.
- **Dependabot** is configured for `gomod` (daily) and `github-actions` (monthly, grouped). Bump via Dependabot PRs, not manual edits.
- **Releases trigger on tag matches `[0-9]+.[0-9]+.[0-9]+`** (see `release.yml`) — the regex is loose (allows `1.2.3.4.5`), but use plain semver tags. GoReleaser runs `go mod tidy` and `go generate ./...` before build.

## CI

- `test.yml` (on PR) — `go test ./...` on `ubuntu-latest`, Go ">=1.20".
- `release.yml` (on tag push) — writes `release.pem` from `secrets.release_key`, runs `goreleaser release --clean`.
- No format or typecheck-only CI; lint is a local/PR discipline, not a CI gate. Do not assume a green PR means lint is clean.
